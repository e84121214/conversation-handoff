# 兩種輸出規格

共用 state 保存目前工作狀態，報告以各模式本次尚未涵蓋的事件為主，必要時帶入前次摘要與連結。新發現的舊事件或對歷史結果的修訂也要納入，並標示事件時間及本次得知時間。

## 脈絡：context.md

讓讀者重建每一步決策的意義與時序，而不是單純列待辦。包含本次期間與基準、前情提要、按時間的研究敘事、相對前次改變、目前結論與未解問題、接續方向。可按日期分節，日期不明則用已知相對順序並標示。

每個有意義的階段連結：當時問題／證據 → 考慮的方案與必要取捨 → 實際決定及理由 → 執行與觀察 → 如何影響下一步。區分討論、決定、執行與事後解讀的時間。理由沒在紀錄中出現時寫「未記錄」，不要事後編造合理故事。失敗或撤回方案若解釋後續選擇就保留。文獻討論記錄支持或反對哪個設計、可用證據與尚未確認主張。

在相應日期標明確認的休息日及未知活動的缺口；不把休息寫成實驗失敗。保持必要研究深度，不強制固定字數，避免逐句重播對話與基礎工具教學。

## 結果：results.xlsx 與 results.md

先讀原始結果檔、設定、log 或實際可見的使用者貼文。過去助理的摘要只能當待核對二手來源。保留來源層級；來源矛盾並列待核對，不能挑較好看的數字。不要為匯出而自行重跑訓練或製造數據。

製作真正的 .xlsx，不以 CSV 改副檔名。使用當前環境可用的試算表工具或適用技能；若無法生成 Excel，交付可用文字並明說結果模式未完成、不推進其成功界線。遵守可用工具的檢查流程。缺少領域專用技能時，本檔規格仍可獨立使用。

依資料規模使用必要工作表，預設：

- **實驗總覽**：穩定實驗／run ID、研究目的、狀態、模型／方法、資料集與版本、切分、樣本數、關鍵設定、基準／比較組、主要觀察與來源。
- **指標明細**：每列為 run × 評估集／子群 × 指標，包含指標名稱、數值、單位、方向、樣本數、閾值／top-k 等評估設定、來源及驗證狀態；適用時另記 seed、重複次數、平均與變異的計算依據。必要時增加便於簡報的寬表，但不能混淆評估母體。
- **設定與來源**：資料處理、特徵、序列／視窗、訓練與評估設定、結果檔位置／對話事件定位，以及重現所需的版本資訊。可與總覽合併，避免空表。

沿用原始 run ID，並讓 Excel、Markdown、state 使用相同 ID。已計畫、失敗、未完成、缺結果的實驗可列總覽，但不冒充已取得指標。缺值留空並用狀態或原因欄說明，不能填 0。沒有任何實測結果時仍可產生清楚標明「無已完成結果」的工作簿與 Markdown，只列已知計畫及缺口，不創造數據。

數字儲存為數值，顯示精度不改原值；單位與百分比尺度明確。保留混淆矩陣原始計數及分母（若有）。衍生指標標示公式與輸入，分母為零時標不可計算。不同樣本切分、時間粒度、前處理、預測目標、測站、threshold、query set 或評估方式不得直接排名；分組呈現並指出可比性限制。單次測試不宣稱統計顯著，沒有重複結果不填標準差或信賴區間。

`results.md` 說明期間、前次基準、本次新增與修訂的實驗、設計與關鍵設定、主要結果表、比較條件、解讀、限制、尚待實驗與來源。觀察與推論分開；選擇性強調最佳結果時也保留失敗／負面結果及比較範圍。前次仍有效但本次未重跑的結果放「沿用基準」，不標為新增。

Excel 凍結表頭、啟用適當篩選、調整欄寬與換行，單位和指標方向清楚。完成後重開或檢查輸出，核對列數、ID、原始計數、關鍵數值、公式與 Markdown 一致；適用時渲染檢查截字與錯誤顯示。記錄無法完成的檢查，不以成功寫檔冒充驗證通過。
